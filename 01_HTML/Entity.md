# 📌 자주 사용하는 HTML 특수 문자

HTML에서는 `<`, `>` 같은 문자가 태그로 인식되기 때문에  
문자를 그대로 출력하려면 **HTML 특수 문자(Entity)** 를 사용해야 합니다.

---

## 🔤 기본 기호

| 문자 | 엔티티(Entity) | 설명 |
|----|----|----|
| < | `&lt;` | 작다 (태그 시작 기호) |
| > | `&gt;` | 크다 (태그 끝 기호) |
| & | `&amp;` | 앰퍼샌드 |
| " | `&quot;` | 큰따옴표 |
| ' | `&apos;` | 작은따옴표 |
| / | `&#47;` | 슬래시 |
| \ | `&#92;` | 백슬래시 |

---

## 🔢 공백 & 정렬 관련

| 문자 | 엔티티 | 설명 |
|----|----|----|
| (공백) | `&nbsp;` | 줄바꿈 없는 공백 |
| (공백 2칸) | `&ensp;` | 짧은 공백 |
| (공백 4칸) | `&emsp;` | 긴 공백 |
| - | `&ndash;` | 짧은 대시 |
| — | `&mdash;` | 긴 대시 |

---

## 💰 통화 기호

| 문자 | 엔티티 | 설명 |
|----|----|----|
| ₩ | `&#8361;` | 원화 |
| $ | `&#36;` | 달러 |
| € | `&euro;` | 유로 |
| ¥ | `&yen;` | 엔 |
| £ | `&pound;` | 파운드 |

---

## ➗ 수학 & 논리 기호

| 문자 | 엔티티 | 설명 |
|----|----|----|
| ± | `&plusmn;` | 플러스 마이너스 |
| × | `&times;` | 곱하기 |
| ÷ | `&divide;` | 나누기 |
| ≠ | `&ne;` | 같지 않음 |
| ≤ | `&le;` | 작거나 같음 |
| ≥ | `&ge;` | 크거나 같음 |

---

## © 등록 & 화살표

| 문자 | 엔티티 | 설명 |
|----|----|----|
| © | `&copy;` | 저작권 |
| ® | `&reg;` | 등록 상표 |
| → | `&rarr;` | 오른쪽 화살표 |
| ← | `&larr;` | 왼쪽 화살표 |

---

## ✅ 사용 예시

```html
<p>5 &lt; 10 은 참입니다.</p>
<p>가격: 10,000&#8361;</p>
<p>&copy; 2025 My Company</p>
