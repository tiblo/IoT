# Javascript 수업 자료 공간

프로그램 = 명령어를 정리하여 나열한 것<br>
개발자가 제시한 순서에 따라 컴퓨터(cpu)가 실행해야 할 명령어 목록

명령어(프로그래밍 언어)
 - 컴퓨터에게 시킬 모든 작업에 해당하는 키워드
 - 입/출력, 계산(연산)[, 판단]

	명령 처리 과정 : 입력 -> [판단 ->] 연산 -> 출력

사용자의 명령 - “버튼을 누르면 글자가 바뀌게 해줘”

컴퓨터에게는 이렇게 지시해야 한다:(단계별로 나눠서)
1. 버튼을 찾아라 - 찾아서 기억
2. 클릭을 감지해라 
3. 글자를 바꿔라

👉 이걸 코드로 쓴 게 프로그래밍


개발 언어 
 - 비프로그래밍 언어 : HTML, CSS 등
 - 프로그래밍 언어 : Javascript, Java, Python 등
 
프로그래밍 언어란?<br>
👉 조건 판단, 반복, 계산, 로직 처리가 가능한 언어

비프로그래밍 언어란?<br>
👉 구조, 내용, 스타일을 “표현”만 하는 언어<br>
👉 논리 판단이나 계산을 직접 수행하지 않음

프로그래밍 언어는 “어떻게 동작할지”를 만들고<br>
비프로그래밍 언어는 “어떻게 보일지”를 정의한다.

프로그래밍의 핵심은 변수<br>
메모리와 변수의 관계는 프로그래밍의 가장 핵심 개념 중 하나

메모리란?<br>
👉 프로그램 실행 중 데이터를 저장하는 공간
- RAM(주기억장치)에 존재
- 프로그램이 실행되면 OS가 메모리를 할당
- 코드, 변수, 객체, 실행 중인 값들이 모두 여기 들어감

변수란?<br>
👉 메모리 공간에 붙인 이름(식별자)
- 값을 저장하기 위한 이름 있는 공간
- 실제 데이터는 메모리에 있고 변수는 그 주소를 가리키는 이름
	
로직이란?<br>
👉 문제를 해결하기 위한 “판단과 처리의 흐름”<br>
입력 -> 판단 -> 처리 -> 결과<br>
이 과정을 어떻게 할지 정해 놓은 규칙과 순서
	
프로그래밍<br>
👉 사람이 로직을 짜서 컴퓨터가 알 수 있는 명령어(프로그래밍 언어)로 작성하는 작업
	
javascript<br>
👉 사용자의 행동에 반응하는 언어
<br>
  사용자 행동(이벤트) -> JavaScript에서 감지 -> 무엇을 할지 결정 -> 화면 변경
